Wetland Loss to Agriculture in a Prairie Pothole Watershed, 2000–2020

Land cover in the Pipestem watershed (HUC8 10160002), North Dakota, mapped from spring Landsat imagery with a random forest classifier. Drag the handle to compare 2000 (left) and 2020 (right).

    Accuracy

    Method. Spring (April–June) median composites of Landsat Collection 2 surface reflectance over 3-year windows (1999–2001, 2009–2011, 2019–2021). One random forest per snapshot, trained on labels from the USDA Cropland Data Layer and the USFWS National Wetlands Inventory. Accuracy is from held-out reference points and is likely optimistic.

    Caveats. 30 m pixels miss many small potholes; "wetland" in a snapshot includes ground that was temporarily flooded that spring; areas are mapped, not error-adjusted. Converted pixels are hard to see when zoomed out — zoom in.

    Full write-up and code: see the README in this project's repository. Imagery: Esri World Imagery. Data: USGS Landsat, USDA NASS CDL, USFWS NWI, USGS WBD.
